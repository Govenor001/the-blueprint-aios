# MCP shortlist

Use this shortlist before searching the full public registry. Every choice still needs a read-only test and owner approval.

|---|---|---|---|

| Custom API | mcp-openapi-proxy | C | Whitelist operations before registering |
| Telegram | Built-in bridge | local | Owner-only chat ID gate |
| GitHub | Composio or official MCP | E/D | Read-only first |
